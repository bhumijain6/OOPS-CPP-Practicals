# Student Management System

## Project Description
A console-based Student Management System developed using C++. It allows users to manage student records efficiently.

## Features
- Add student records
- Display all students
- Search students by roll number
- Update student marks
- Delete student records
- Calculate grades
- Save and load records using file handling

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Exception Handling

## STL Concepts
- Vector
- Algorithms (`find_if`, `remove_if`)

## Technologies
- C++
- STL
- File Handling
- Git and GitHub

## How to Run

Compile:
`g++ -std=c++17 main.cpp Student.cpp StudentManager.cpp -o StudentManagement.exe`

Run:
`.\StudentManagement.exe`
